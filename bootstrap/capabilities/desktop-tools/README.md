# Desktop tools capability

This capability links small desktop application files to their first-party repository sources. Both registered Macs receive Go's local-only telemetry mode. The personal Mac additionally receives LinearMouse, NextDNS, mactop, and herdr configuration. Application writes therefore update the checkout. The NextDNS file is configuration text only: this capability does not activate DNS or update its addresses.

Run `mise desktop-tools` or `mise laptop -t desktop-tools`. Add `--check` for a nonmutating preview. The focused task needs no credentials.
