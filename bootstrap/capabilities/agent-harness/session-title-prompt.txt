# Rules

- Keep the articles before common nouns: the, a, an. Proper names and identifiers take none.
- Keep the concrete identifiers the operator would search for: ticket keys, PR numbers, and service, file, host, or tool names. Make them the target, not a tag.
- Aim for under 60 characters. Hard cap: 80.
- Name the overall mission, not the latest step.
- Sentence case. No trailing punctuation.
