# Terminal tools

Owns shared tmux configuration, Ghostty configuration, and terminal helpers. `tmux.conf.tera` and `ghostty/config.tera` are single templates: on Omarchy, tmux layers on top of Omarchy's own tmux config and theme, and Ghostty renders `config.ghostty`, which loads after Omarchy's `config`; on pod042 it renders the same file with its own font and light/dark theme pair. Host manifests select platform resources. TPM checkout and plugin installation are enabled on personal hosts only. Personal Mac reconciliation updates TPM; pod042 keeps its existing checkout unless explicitly updated. Work instead runs `clipcopy/install`, which builds `~/Applications/ClipCopy.app` whenever the hash of `ClipCopy.applescript` and the installer, stamped in its Info.plist, differs. The app is background-only and handles `clipcopy:<percent-encoded text>` links by copying the decoded text, so a click on an agent's link copies a message without the terminal's wrapping or losing focus.

Run `mise terminal-tools` (alias `mise tmux`) or add `--check`. Check mode renders and resolves resources without cloning or running hooks. Software prerequisites remain in the Brewfiles and pod042's base (tmux, as a system host tool) and operator capabilities; full reconciliation installs them before this capability runs.
