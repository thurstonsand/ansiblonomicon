# pod042 agent harness

`mise.agent-harness.toml` runs the native adapter as the operator after the operator capability installs Python 3.14, uv and Git. The adapter uses the common deployment engine in `bootstrap/capabilities/agent-harness`, explicitly selecting the `pod042` profile and `pod042` template hostname. It reads `catalogue.toml`, `profiles.toml`, each targeted harness's native `mise.toml`, and the canonical model catalogue (`bootstrap/capabilities/agent-harness/models.yml`). It does not copy another machine's generated files.

The adapter owns catalogue skills, supported subagent files, the hook fragment cache, and any `[dotfiles]` or `[bootstrap.files]` resources composed by an enabled harness declaration. Unchanged local-source files are symlinked to this repository, Git-source files are copied, and templates or harness-transformed outputs are real files. Native `agent-config` owns user instructions, canonical models, settings, extensions, and platform packages, rendering hook fragments directly into native harness configurations. Amp receives only explicitly targeted machine-local skills; hosted catalogue publishing remains separate.

The command refuses execution outside pod042 or outside the operator's UID/GID 1000 and Linux home. Git sources use the existing harness cache and fast-forward updates. Jinja templates render with pod042 facts; file lookups stay inside the checkout and unsupported lookup plugins fail rather than requesting credentials.

Reconciliation records exact per-plugin ownership in `.cache/ansiblonomicon-harness/pod042-managed-files.json`. Omitting a plugin preserves both its paths and source-plus-plugin provenance; declaring that identity with `remove = true` retires only those recorded paths, even offline. There is no whole-directory prune, so independently installed skills from Codex, Pi packages or the operator remain in place. Run the script with `--check` to compare already cached sources without writes or network updates. A first-run check requires the source cache to exist. Native bootstrap check mode previews the hook but does not execute it.
