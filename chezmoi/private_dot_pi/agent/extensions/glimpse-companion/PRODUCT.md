# Product

## Register

product

## Users

The Glimpse Companion is for a developer/operator running one or more Pi sessions while staying focused in the terminal. It lives in peripheral vision near the cursor and helps map agent activity back to the project or folder responsible for it.

## Product Purpose

Show compact, theme-native session state without becoming a dashboard. The companion should make active work and required intervention legible at a glance, while staying small enough to remain part of the terminal workflow rather than a separate monitoring surface.

## Brand Personality

theme-native, unobtrusive, informational

## Anti-references

Not heavy in screen real estate. Not a dashboard. Not macOS-native chrome. Not notification-center noise. It should feel like Pi: terminal-native, compact, stateful, and direct.

## Design Principles

- **Terminal-native first.** The companion should inherit the active Pi theme and feel like a terminal-adjacent status surface, not a separate app skin.
- **Priority without ceremony.** Important state should become easier to see, but the UI should avoid headers, panels, badges, or extra structure unless the state genuinely needs them.
- **Stable peripheral state.** Ordinary activity changes should not cause distracting reshuffles, animation resets, or visual jumps.
- **Folder identity is primary.** The project/folder label is the most important text. Other labels are useful, but they may yield first when space is tight.
- **Density with restraint.** Compactness is a core constraint, but it must preserve scanability and clear state changes.

## Accessibility & Inclusion

Text should meet WCAG AA contrast against the companion surface. Color should not be the only signal for attention or status. Motion should communicate state without becoming decorative noise.
