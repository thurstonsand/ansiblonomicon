# Garden hose install on cedar siding

## Question

Install a garden hose setup: looking at a combo of an **Eley wall-mount hose reel**, hose, and nozzle. Understand how the wall mounting is supposed to work on **cedar siding**: what tools are needed, whether a gasket/sealant/spacer is required, and how to find studs from the outside. Primary sources: Eley's own mounting instructions and hardware list, siding-manufacturer guidance on fastening through cedar lap siding, stud-finding methods for exterior walls (nail lines, measurement from corners/windows, magnetic vs electronic finders).

## Resolution

[Garden hose install on cedar siding research](../research/garden-hose-install.md) specifies a two-stud, four-lag installation with rigid pass-through spacers and sealed sheathing penetrations so the cedar carries no clamp load. Locate studs indoors and transfer from a shared window reference, then prove them with pilot holes; use a flashed platform only when framing is not 16 inches on center. The filled 125-foot setup is about 55 lb before hose-pull loads.
