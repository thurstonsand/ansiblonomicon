# Cameras and doorbell

## Question

- first identify the exterior cameras that came with the house, find their recorder or hub (possibly the locked box in the basement), learn how to access them, and determine whether they can integrate with the intended system
- interior ubiquiti cameras? needs ethernet ([Ethernet, rack, and cellular](02-ethernet-rack-cellular.md))
- doorbell: currently dumb. Options: wifi doorbells needing only power, or ubiquiti PoE doorbell (already heavy ubiquiti). Decide

The contractor may be able to install replacement or additional cameras, but the existing system should be understood before deciding what to replace.
